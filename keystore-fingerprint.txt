# SHA-256 fingerprint of the certificate in dotabyss.keystore.
#
# build.py compares the keystore it is about to sign with against this value and
# refuses to build on a mismatch. That is what catches the case where an earlier run
# generated a fresh keystore: the file exists, so nothing else would ever complain,
# and the wrong signature only shows up as players losing their save data.
#
# This is NOT a secret. A fingerprint comes from the public certificate and anyone
# can read it off a published APK. The private key lives in dotabyss.keystore;
# this file only ever holds the public fingerprint. Committing it is the point.
#
# ---------------------------------------------------------------------------------
# PINNED 2026-09-13. The original keystore was lost in the machine move and cannot be
# recovered, so the project changed signing identity on this date, starting with the
# v1.10.1 rebuild. APKs from before 2026-09-13 carry the old signature and cannot be
# updated in place by anything signed with this key.
#
# To re-check by hand:
#
#   keytool -list -v -keystore dotabyss.keystore -alias dotabyss
#   apksigner verify --print-certs dist/DotAbyssX-R18-zh-Hant.apk
