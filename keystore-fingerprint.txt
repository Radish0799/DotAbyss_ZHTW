# SHA-256 fingerprint of the certificate in dotabyss.keystore.
#
# build.py compares the keystore it is about to sign with against this value and
# refuses to build on a mismatch. That is what catches the case where an earlier run
# generated a fresh keystore: the file exists, so nothing else would ever complain,
# and the wrong signature only shows up as players losing their save data.
#
# This is NOT a secret. A fingerprint comes from the public certificate and anyone
# can read it off a published APK. The private key lives in dotabyss.keystore, which
# .gitignore keeps out of here. Committing this file is the point.
#
# ---------------------------------------------------------------------------------

#
# To pin it, once the original keystore is restored:
#

#
